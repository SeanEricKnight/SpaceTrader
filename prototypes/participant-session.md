# Firefly pilot · facilitator sheet

Open inspect-ship.html from the extracted prototypes folder. Append `?study=1&mode=static` or `?study=1&mode=animated` to its address before presenting it. Confirm the comparison switch is hidden. Run locally. Use anonymous IDs and record actual viewport, input type, game familiarity, assigned condition, actual reduced-motion state and any assistance. Respect motion preferences; flag animated assignments rendered static.

Recruit eight first-exposure participants for a formative pilot. Within each device class, shuffle two static and two animated slips before assigning people in arrival order. Record familiarity to see any imbalance. Stop at eight or sooner for an access failure. Do not swap versions before scoring. A comparison with eight people can identify usability failures; it cannot resolve modest differences or establish equivalence.

## Read aloud
“You can explore this ship for up to 90 seconds. Tell me when you’re ready.” Start at the overview. Count elapsed time, including opening, moving parts and pauses. Stop on discomfort. Next ask “Show me where the ship carries freight.” Then “Show me the equipment that protects against incoming hits.” Allow 30 seconds each. Record first choice, eventual correctness, seconds from prompt to selection and number of actions per task. Avoid hints. Record timeouts separately.

Close the inspection and hide the overview. Ask the following without feedback. Record answers verbatim. Have a scorer who cannot see the assigned mode award one point per item using the criteria in parentheses.

1. What is the difference between a shield slot and a fitted shield? (Capacity to install versus working equipment; this example has a shield installed.)
2. What changes if the ship gains five cargo bays? What happens to its laser mounts? (Five more units of capacity; laser mounts unchanged.)
3. With 12 of 20 bays used, can you take nine more units? (No; short by one.)
4. Four more units of freight are accepted. How many bays are now free? (Four.)
5. A fitted shield reduces each hit by five, with a minimum of one. What gets through on a three-point hit? (One.)
6. Would moving the illustrated crew quarters change a combat outcome? Why? (No; placement is illustrative.)

Optional spatial probe after the six answers: show the same assembled image cropped to remove labels and number tags; ask the participant to point out the engine exhausts. Use the same masked image for everyone. Record separately; skip for everyone if the masked stimulus is unavailable.

Ask “How enjoyable was inspection?” (1–7) and “Did anything feel uncomfortable?” Record separately. Give a two-minute unrelated sorting task. Then make the overview available for one minute, saying only “You may use this time however you like.” Record whether they reopen inspection without prompting. Ask what they were trying to do only afterward. Do not count facilitator-requested reopening. Optional crossover for preference follows all measures.
