# Developer cheat console

On desktop, click outside text inputs and type **`cheats`**. Alternatively, click the **Space Trader** title five times rapidly. Close a bank dialog first. The typing shortcut deliberately ignores text fields and open dialogs.

Enter a command in the console and press Run. Successful state-changing commands mark **Cheats used this run** and that flag is saved. Use `help` inside the console for the current command list.

| Command | Effect |
| --- | --- |
| `cash` | Add 100,000 credits |
| `cash 50000` | Add the specified positive whole-credit amount; balance is capped |
| `heal` | Restore hull |
| `fuel` | Fill the fuel tank |
| `god` | Toggle invincibility |
| `peace` | Toggle random pirate encounters |
| `warp Adahn` | Travel instantly to a named port without fuel or a travel day |
| `ship Wasp` | Grant the named ship, compatible lasers, and full hull/fuel; cargo must fit |
| `encounter` | Create a pirate encounter for testing |
| `debt` | Clear the current loan |
| `empty` | Empty cargo, failing cargo-dependent missions as appropriate |
| `win` | Mark the commander retired immediately |
| `resume` | Resume a retired or destroyed run with full hull |
| `close` | Close the console |

These shortcuts are intentional test tools. They are separate from normal financing, mission rewards, and the free stranded-rescue service. A new game starts a fresh run without the cheat flag.
