# Attribution and adaptation notes

## Browser playtest build

This is an unofficial browser adaptation based on Space Trader by Pieter Spronck. The supplied original source header credits Pieter Spronck, additional coding by Sam Anderson and Samuel Goldstein, and use of code from Matt Lee’s Dope Wars. The original program also cites Elite as an inspiration.

The supplied source header specifies GNU General Public License version 2 or, at the recipient’s option, a later version. The browser HTML retains its `GPL-2.0-or-later` declaration. The supplied GPL v2 text is reproduced in `licenses/GPL-2.0.txt`, and the supplied original README is retained in `licenses/ORIGINAL_README.txt`.

The current browser game uses adapted catalogs and simplified mechanics, new JavaScript/CSS presentation, original setting and character text, procedural planet textures, and the previously generated embedded ship artwork. It does not display the original Palm game’s in-game pictures. It is not an official Space Trader or Dark Nova release.

The supplied Dark Nova II, Java/Windows Space Trader, and Endless Sky archives informed earlier design review. Their complete engines and asset collections are not bundled with this browser update. This notice describes the project’s provenance; it does not claim an independent compatibility audit of every reference archive.

The program is supplied without warranty; see the license text. This archive updates the browser prototype only. It does not represent a tested, signed, or App Store-ready iPhone application.


## Native iPhone adaptation

This is an unofficial iPhone adaptation based on Space Trader 1.2.2 by Pieter Spronck, copyright 2000, 2001, 2002, 2005. The original source credits additional coding by Sam Anderson and Samuel Goldstein and identifies code used from Matt Lee's Dope Wars.

The original source headers specify GNU General Public License version 2 or (at your option) any later version. New adaptation code is provided under the same GPL-2.0-or-later terms. The full original license is included at `SpaceTrader/LICENSE.txt`. This code is supplied without warranty; see that license.

Changes made November 13, 2026: new Swift engine, SwiftUI iPhone interface, local JSON persistence, Xcode project, core test package, and extracted original catalogs. The galaxy generation, economy, combat, equipment progression, courier jobs, and retirement rules are simplified adaptations. This is not an official release by the original author.

The supplied archive and original README are included unchanged in substance. The original archive's README includes an older request to consult the author about ports and distribution. In a later website excerpt supplied in this conversation, the author explicitly states that he has no objections to iPhone conversions under the GPL and describes an earlier conversion called Dark Nova. That excerpt has not been independently checked for date or present App Store availability. No contact with the original author has been made as part of this work. Original in-game pictures are identified there as copyrighted by Alexander Lawrence; the new app does not load or display those pictures.
